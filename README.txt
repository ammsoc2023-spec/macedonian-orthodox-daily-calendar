Fourth app: a copy of the Macedonian Orthodox Daily app (same calendar, corrected 2026 readings, prayers, Bible/Biblija tabs,
read-aloud, intros and commentary, auto-update), with the English Scripture of every reading taken from The Orthodox Study Bible
(NKJV New Testament; Septuagint Old Testament), used by permission.

Static files only. Serve this folder over HTTPS (GitHub Pages). Open the URL on the phone once (it caches all 365 days), then:
 iPhone (Safari): Share → Add to Home Screen.   Android (Chrome): menu ⋮ → Install app / Add to Home screen.
Data: data/2026-MM.json (one per month), data/index.json (search), data/about.json.
Own storage names so it can live next to the other apps on the same github.io site: cache modc2026-<hash> / modc-icons-v1, localStorage keys modc.*.
English Scripture build: /workspace/modc_tools (osb_pdf_db.py -> osb_verses.json from the OSB PDF; build_osb.py --write; spotcheck.py / fullcheck.py).
Day icons: img/icons/*.webp from Wikimedia Commons (credits in data/icons.json).
